Cuándo usarme: cuando se añada o cambie una pieza que hace cuentas.

Cómo escribir las pruebas

1. Lee la pieza y haz una lista de sus casos raros:
   vacío, cero, negativo, el límite, el formato equivocado.
2. Una prueba por comportamiento, con nombre en ingles
   que diga qué comprueba.
3. Nada de piezas falsas. Si hacen falta, el problema
   es el diseño: dilo y para.

Al terminar
Corre las pruebas y pega el resultado tal cual.
Si sale rojo, la prueba encontró un error de verdad:
avísame. NO cambies el número esperado para que pase.
